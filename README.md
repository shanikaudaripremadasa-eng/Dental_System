*  Demonstration of Academic Project: "Online Dental Appointment & Patient Management System"

Designed to streamline clinical administration, this web application simplifies patient registration, record management, and doctor appointment scheduling workflows.

> Note: As an academic prototype built for learning and practical application, there is always room for further enhancement. I would highly appreciate your professional feedback and recommendations!

# Key Functional Highlights

* Secure Authentication: Implemented JWT & Bcrypt for user login & role-based access.
* Appointment Management: Real-time scheduling for patients and schedule tracking for doctors.
* Patient Records: Structured database management for patient profiles and history.
* Seamless Integration: Fully responsive UI connected via RESTful APIs.

# Tech Stack

* Frontend: Angular, HTML5, CSS3, Bootstrap
* Backend: Node.js, Express.js
* Database: MongoDB
* Security & Tools: JWT, Bcrypt, Git/GitHub, Postman
